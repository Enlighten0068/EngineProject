Detailed Description

2D camera with orthographic projection, position, rotation, and zoom.

The Camera2D class manages an orthographic projection matrix and a view matrix based on the camera's position, rotation (around Z-axis), and zoom level. It is used to define what part of the world is visible on screen.

Note
The camera uses a dirty flag to avoid recalculating the view matrix every frame unless the position or rotation has changed.

void Camera2D::Update ( )

Updates the view matrix if the camera is dirty. Should be called before rendering if the camera has moved or rotated.

Updates the view matrix ONLY when the camera is dirty.

The view matrix is the inverse of the camera's transform:

  1. Apply translation to -position
  2. Apply rotation around Z-axis (inverse angle)
