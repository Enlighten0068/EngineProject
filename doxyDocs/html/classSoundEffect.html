Detailed Description

Handles a sound effect that is loaded from a .wav file.

It uses SDL3 audio stream API to manage the loading, playback and unloading of audio data.

Opens the shared audio device if not already open.

Opens the shared audio device with default parameters.

Returns
true if the device is (or was) successfully opened, false otherwise.

The device is configured for 44.1 kHz, 16-bit stereo audio. This is a one-time initialization - subsequent calls are ignored if the device is already open.

Returns
