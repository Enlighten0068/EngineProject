Detailed Description

Abstract base class for all scenes in the engine.

A scene represents a distinct game state or screen (e.g., menu, gameplay, pause). Each scene must implement lifecycle methods: OnEnter, OnExit, Update, and Render.

Note
Scenes are managed by the SceneManager.
