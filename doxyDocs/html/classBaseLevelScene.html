Detailed Description

Generic scene that builds its content from a LevelSystem builder function.

This scene replaces the old Demo2DFixedScene for level-based gameplay. It receives a builder function (e.g., BuildLevel1) and a camera mode, and uses them to construct and run the level. Pressing ESC returns to the level selector.

See also
LevelSystem, LevelSelectorScene, LevelRegistry
