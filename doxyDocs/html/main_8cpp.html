int main ( )

Entry point for the EngineProject application.

Creates the main Application instance, initializes all engine subsystems, and selects the initial scene based on the DEMO_2D_FIXED preprocessor macro.

If DEMO_2D_FIXED is defined, the application starts directly in the Demo2DFixedScene (a 2D platformer demo with a fixed camera). Otherwise, it starts in the MenuScene, allowing the user to navigate to different game modes.

Returns
int Returns 0 on successful execution, 1 if initialization fails.
