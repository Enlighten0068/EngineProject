Detailed Description

Wrapper for a TrueType font using SDL_ttf.

This class manages loading a font from a file and rendering text to OpenGL textures. It supports setting font size and style.

Note
The font is loaded from a TTF file and rendered to SDL_Surface, which can then be converted to an OpenGL texture.

Renders a string to an SDL_Surface.

The surface can be converted to an OpenGL texture for rendering.

Parameters

Returns
SDL_Surface* containing the rendered text, or nullptr on failure. The caller is responsible for freeing the surface.

Uses SDL_ttf to render the text with the specified color. The surface is in SDL_PIXELFORMAT_ARGB8888 format, which can be converted to an OpenGL texture.
