Detailed Description

OpenGL Vertex Array Object (VAO) wrapper.

A VAO stores the vertex attribute configuration for a vertex buffer. It encapsulates the state of vertex attributes (position, texture coordinates, etc.).

Note
The VAO must be bound before configuring vertex attributes.
