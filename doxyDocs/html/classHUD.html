Detailed Description

Simple heads-up display overlay for rendering text on top of scenes.

The HUD renders a list of text lines at the top-right corner of the screen using screen-space pixel coordinates. Text textures are cached by content (text + color) to avoid re-rasterizing the same string every frame.

Rendered by Application after the scene, so it always appears on top.

See also
Scene::GetHUDLines, Application::Render
