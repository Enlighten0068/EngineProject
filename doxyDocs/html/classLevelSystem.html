Detailed Description

System that provides a high-level API for building game levels.

The LevelSystem accumulates entities as they are created and records the world bounds. The GameWorld itself is created by the scene after the level is built (via GetWorldBounds accessors). This separation avoids copying a non-copyable GameWorld.

Each level is defined in a separate .cpp file as a function that receives a reference to a LevelSystem and calls its methods.

See also
BaseLevelScene, LevelRegistry, REGISTER_LEVEL
