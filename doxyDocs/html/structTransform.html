Detailed Description

Represents a 3D transformation: position, rotation, and scale.

This struct is used as a component in the ECS system to store the spatial properties of an entity.

Note
Rotation is stored as Euler angles (pitch, yaw, roll) in radians. Usually only the roll is used in 2D games.
