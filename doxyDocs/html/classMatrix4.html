Detailed Description

4x4 matrix class for 3D transformations and projections.

The matrix is stored in column-major order (OpenGL style), meaning the data array is organized as:

[ col0, col1, col2, col3 ]

where each column is a Vector4.

Note
All static methods return a new Matrix4 instance.
