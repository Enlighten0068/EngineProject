Detailed Description

Main menu scene with visual text rendering.

The MenuScene provides a graphical menu with options rendered using SDL_ttf. Navigation is done with arrow keys / D-pad, mouse clicks, and selection with Enter / Space / A button.

Note
This scene requires a font file to be present in assets.
