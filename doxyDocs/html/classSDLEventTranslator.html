Detailed Description

Translates SDL events into engine events and dispatches them via EventBus.

This class is responsible for converting low-level SDL events (SDL_Event) into engine-specific event objects and dispatching them to the EventBus.

Note
All methods are static; this class is not meant to be instantiated.
