Detailed Description

Event representing a keyboard key press/release.

Contains information about which key was pressed, the action type, and the state of modifier keys (Ctrl, Shift, Alt).

Note
This event is dispatched by SDLEventTranslator.
See also
SDLEventTranslator, EventBus
