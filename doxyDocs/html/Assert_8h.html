Asserts a condition and aborts the program if it fails.

If the condition evaluates to false, logs an error message with the file name and line number, then terminates the program with std::abort().

Parameters
conditionThe condition to evaluate.
messageThe error message to log if the condition fails.
Note
Should be used only in debug builds.
