\doxysubsection{Detailed Description}
Centralized manager for Open\+GL graphics resources. 

The \doxylink{classGraphicsContext}{Graphics\+Context} is responsible for creating and managing all Open\+GL resources used by the engine: shaders, vertex array objects, vertex buffers, and index buffers. It encapsulates the Open\+GL initialization and provides access to these resources.

\begin{DoxyNote}{Note}
This class should be initialized after the Open\+GL context is created. 
\end{DoxyNote}
