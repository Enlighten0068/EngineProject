\doxysubsection{Detailed Description}
Open\+GL Index Buffer Object (EBO/\+\+IBO) wrapper. 

An index buffer stores vertex indices for indexed drawing (gl\+Draw\+Elements). This allows reusing vertices and reduces memory usage.

\begin{DoxyNote}{Note}
The buffer is created with GL\+\_\+\+STATIC\+\_\+\+DRAW usage. 
\end{DoxyNote}
