\doxysubsection{Detailed Description}
Open\+GL shader program wrapper. 

Manages the compilation, linking, and usage of vertex and fragment shaders. Provides methods for setting uniform values (matrices, vectors, and floats).

\begin{DoxyNote}{Note}
Shaders are compiled from source strings at runtime. 
\end{DoxyNote}
