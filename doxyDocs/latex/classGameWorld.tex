\doxysubsection{Detailed Description}
Defines the boundaries of the game world and provides clamping. 

The \doxylink{classGameWorld}{Game\+World} class holds the minimum and maximum coordinates of the world in both X and Y axes. It provides a Clamp\+Position method to keep entities within these bounds and renders the world borders.
