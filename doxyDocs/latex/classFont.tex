\doxysubsection{Detailed Description}
Wrapper for a True\+Type font using SDL\+\_\+ttf. 

This class manages loading a font from a file and rendering text to Open\+GL textures. It supports setting font size and style.

\begin{DoxyNote}{Note}
The font is loaded from a TTF file and rendered to SDL\+\_\+\+Surface, which can then be converted to an Open\+GL texture. 
\end{DoxyNote}
