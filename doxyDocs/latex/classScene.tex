\doxysubsection{Detailed Description}
Abstract base class for all scenes in the engine. 

A scene represents a distinct game state or screen (e.\+g., menu, gameplay, pause). Each scene must implement lifecycle methods: On\+Enter, On\+Exit, Update, and Render.

\begin{DoxyNote}{Note}
Scenes are managed by the \doxylink{classSceneManager}{Scene\+Manager}. 
\end{DoxyNote}
