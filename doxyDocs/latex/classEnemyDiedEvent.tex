\doxysubsection{Detailed Description}
\doxylink{classEvent}{Event} dispatched when an enemy dies. 

Contains the enemy\textquotesingle{}s position at death and the score value awarded.

\begin{DoxyNote}{Note}
This event can be used by UI systems to update score or by audio systems to play death sounds. 
\end{DoxyNote}
