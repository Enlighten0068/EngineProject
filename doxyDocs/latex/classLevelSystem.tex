\doxysubsection{Detailed Description}
System that provides a high-\/level API for building game levels. 

The \doxylink{classLevelSystem}{Level\+System} accumulates entities as they are created and records the world bounds. The \doxylink{classGameWorld}{Game\+World} itself is created by the scene after the level is built (via Get\+World\+Bounds accessors). This separation avoids copying a non-\/copyable \doxylink{classGameWorld}{Game\+World}.

Each level is defined in a separate .cpp file as a function that receives a reference to a \doxylink{classLevelSystem}{Level\+System} and calls its methods.
