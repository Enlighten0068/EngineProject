\doxysubsection{Detailed Description}
Core engine class responsible for window creation and SDL lifecycle. 

The \doxylink{classEngine}{Engine} class abstracts the low-\/level window management and SDL initialization. It owns the \doxylink{classSDLWindow}{SDLWindow} and manages the main loop\textquotesingle{}s running state.
