\doxysubsection{Detailed Description}
Adds physics properties to an entity. 

Entities with this component are affected by gravity and can participate in collision detection and resolution. The velocity is updated each frame by the physics system.

\begin{DoxyNote}{Note}
This component is used for both the player and enemies. 
\end{DoxyNote}
