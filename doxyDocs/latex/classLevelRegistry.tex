\doxysubsection{Detailed Description}
Global registry of all levels. 

Levels register themselves at program startup via static initialization (see \doxylink{LevelMacros_8h}{Level\+Macros.\+h}). This allows adding new levels without modifying any central file — just create a new .cpp, add it to CMake\+Lists.\+txt, and the selector will list it automatically.

\begin{DoxyNote}{Note}
This class is a singleton. 
\end{DoxyNote}
