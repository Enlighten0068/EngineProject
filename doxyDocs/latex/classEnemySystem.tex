\doxysubsection{Detailed Description}
System that updates enemy entities with patrol, physics, and collision. 

The \doxylink{classEnemySystem}{Enemy\+System} processes all entities that have the Enemy, Patrol, and Physics\+Body components. It handles:


\begin{DoxyItemize}
\item Horizontal patrol movement between two points
\item Gravity and vertical velocity
\item Collision detection and resolution with platforms
\item Grounded state detection
\item World boundary clamping
\end{DoxyItemize}

\begin{DoxyNote}{Note}
This system is designed to be called once per frame from the scene\textquotesingle{}s \doxylink{classEnemySystem_a122dd4911d2670f242ec120e6a82081e}{Update()}. 
\end{DoxyNote}

Updates all active enemy entities. 

This method iterates over all entities with \doxylink{structTransform}{Transform}, Enemy, Patrol, and Physics\+Body components. For each active enemy, it:
\begin{DoxyEnumerate}
\item Moves the enemy horizontally according to its patrol path.
\item Applies gravity to the enemy\textquotesingle{}s vertical velocity.
\item Checks and resolves collisions with platforms.
\item Clamps the enemy to the world floor.
\item Updates the grounded state.
\end{DoxyEnumerate}
