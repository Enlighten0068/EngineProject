\doxysubsection{Detailed Description}
Singleton resource manager for loading and caching assets. 

The \doxylink{classResourceManager}{Resource\+Manager} provides a centralized system for loading and caching assets such as textures and shaders. It ensures that each asset is loaded only once and shared across the engine, reducing memory usage and load times.

Supported assets: textures and shaders.

\begin{DoxyNote}{Note}
This is a singleton; use \doxylink{classResourceManager_a98b11a6302bf0db4ffc81eea70512ee2}{Get\+Instance()} to access it. 
\end{DoxyNote}
