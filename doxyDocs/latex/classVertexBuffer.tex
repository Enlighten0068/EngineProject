\doxysubsection{Detailed Description}
Open\+GL Vertex Buffer Object (VBO) wrapper. 

A VBO stores vertex data (positions, texture coordinates, normals, etc.) in GPU memory.

\begin{DoxyNote}{Note}
The buffer is created with GL\+\_\+\+STATIC\+\_\+\+DRAW usage. 
\end{DoxyNote}
