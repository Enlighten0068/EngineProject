\doxysubsection{Detailed Description}
Base class for all events in the engine. 

All events derive from this class and must implement \doxylink{classEvent_af14bbd8f69c2778def9462375a0e70f2}{Get\+Event\+Type()}. The Handled flag can be used by event dispatchers to mark an event as processed.

\begin{DoxyNote}{Note}
Events are typically dispatched via \doxylink{classEventBus}{Event\+Bus} or \doxylink{classEventDispatcher}{Event\+Dispatcher}. 
\end{DoxyNote}
