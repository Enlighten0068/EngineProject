\doxysubsection{Detailed Description}
Main menu scene with visual text rendering. 

The \doxylink{classMenuScene}{Menu\+Scene} provides a graphical menu with options rendered using SDL\+\_\+ttf. Navigation is done with arrow keys / D-\/pad, mouse clicks, and selection with Enter / Space / A button.

\begin{DoxyNote}{Note}
This scene requires a font file to be present in assets. 
\end{DoxyNote}
