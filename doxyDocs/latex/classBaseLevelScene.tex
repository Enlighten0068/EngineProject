\doxysubsection{Detailed Description}
Generic scene that builds its content from a \doxylink{classLevelSystem}{Level\+System} builder function. 

This scene replaces the old \doxylink{classDemo2DFixedScene}{Demo2\+DFixed\+Scene} for level-\/based gameplay. It receives a builder function (e.\+g., Build\+Level1) and a camera mode, and uses them to construct and run the level. Pressing ESC returns to the level selector.
