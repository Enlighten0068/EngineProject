\doxysubsection{Detailed Description}
Static rendering API for drawing 2D geometry. 

The \doxylink{classRenderer}{Renderer} provides a simple interface for drawing textured or untextured quads using the engine\textquotesingle{}s shader and buffer objects. All methods are static, making it easy to use from anywhere in the engine.

\begin{DoxyNote}{Note}
The \doxylink{classRenderer}{Renderer} assumes that the shader already has the correct uniforms for the model, view, and projection matrices, as well as a texture sampler. 
\end{DoxyNote}
