\doxysubsection{Detailed Description}
Translates SDL events into engine events and dispatches them via \doxylink{classEventBus}{Event\+Bus}. 

This class is responsible for converting low-\/level SDL events (SDL\+\_\+\+Event) into engine-\/specific event objects and dispatching them to the \doxylink{classEventBus}{Event\+Bus}.

\begin{DoxyNote}{Note}
All methods are static; this class is not meant to be instantiated. 
\end{DoxyNote}
