\doxysubsection{Detailed Description}
Marks an entity as an enemy. 

This is a tag component used by the \doxylink{classEnemySystem}{Enemy\+System} to identify and process enemy entities. It contains a flag to enable/\+disable the enemy without destroying the entity.

\begin{DoxyNote}{Note}
This component is used in conjunction with \doxylink{structComponents_1_1Transform}{Transform}, \doxylink{structComponents_1_1Patrol}{Patrol}, and \doxylink{structComponents_1_1PhysicsBody}{Physics\+Body}.
