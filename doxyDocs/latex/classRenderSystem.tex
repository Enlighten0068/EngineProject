\doxysubsection{Detailed Description}
System that renders all entities with \doxylink{structTransform}{Transform} and Sprite\+Renderer components. 

The \doxylink{classRenderSystem}{Render\+System} is responsible for drawing all visible entities in the scene. It processes entities that have both a \doxylink{structTransform}{Transform} (position, rotation, scale) and a Sprite\+Renderer (texture) component, calculates the model matrix, and calls the \doxylink{classRenderer}{Renderer} to draw each entity.

Entities with a Tile\+Scale component use its value; entities without Tile\+Scale default to 1.\+0f (no repetition, texture stretches to fill the quad).

\begin{DoxyNote}{Note}
This system should be called once per frame from the scene\textquotesingle{}s \doxylink{classRenderSystem_a0dee88c7afdb4acfa6ad44e3902ce7a3}{Render()} method. 
\end{DoxyNote}

Renders all entities with \doxylink{structTransform}{Transform} and Sprite\+Renderer components.
