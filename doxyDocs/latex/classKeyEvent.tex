\doxysubsection{Detailed Description}
\doxylink{classEvent}{Event} representing a keyboard key press/\+release. 

Contains information about which key was pressed, the action type, and the state of modifier keys (Ctrl, Shift, Alt).

\begin{DoxyNote}{Note}
This event is dispatched by \doxylink{classSDLEventTranslator}{SDLEvent\+Translator}. 
\end{DoxyNote}
