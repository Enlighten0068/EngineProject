\doxysubsection{Detailed Description}
2D camera with orthographic projection, position, rotation, and zoom. 

The \doxylink{classCamera2D}{Camera2D} class manages an orthographic projection matrix and a view matrix based on the camera\textquotesingle{}s position, rotation (around Z-\/axis), and zoom level. It is used to define what part of the world is visible on screen.

\begin{DoxyNote}{Note}
The camera uses a dirty flag to avoid recalculating the view matrix every frame unless the position or rotation has changed. 
\end{DoxyNote}
