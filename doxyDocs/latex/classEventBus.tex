\doxysubsection{Detailed Description}
Singleton event bus for global event dispatching. 

The \doxylink{classEventBus}{Event\+Bus} allows any part of the engine to subscribe to events and be notified when they occur. It uses type-\/based subscription (via std::\+type\+\_\+index) for type-\/safe event handling.

\begin{DoxyNote}{Note}
This is a singleton; use \doxylink{classEventBus_abb3a69dd93dc265aec144024ab8ab3ed}{Get\+Instance()} to access it. 
\end{DoxyNote}
