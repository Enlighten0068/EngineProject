\doxysubsection{Detailed Description}
Utility class for dispatching events to specific handlers. 

\doxylink{classEventDispatcher}{Event\+Dispatcher} allows type-\/safe event handling by checking the event type and casting to the appropriate derived class before invoking the callback.

\begin{DoxyNote}{Note}
This is a lightweight wrapper; for global event handling, use \doxylink{classEventBus}{Event\+Bus}. 
\end{DoxyNote}
