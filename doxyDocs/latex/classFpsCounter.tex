\doxysubsection{Detailed Description}
Utility class for measuring and logging frames per second. 

This class calculates the average FPS over a configurable interval, and logs it to the console. It also provides access to delta time and elapsed time values.

\begin{DoxyNote}{Note}
FPS is calculated as frame count divided by elapsed time over the logging interval. 
\end{DoxyNote}

Updates the FPS counter (should be called once per frame). 

Updates the FPS counter and logs when interval elapses.

This method increments the frame count and, when the interval has elapsed, calculates and logs the average FPS.

This method should be called once per frame. It accumulates delta time and frame count, and when the interval is reached, it calculates the average FPS and logs it.
