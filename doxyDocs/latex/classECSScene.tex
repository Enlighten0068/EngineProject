\doxysubsection{Detailed Description}
\doxylink{classScene}{Scene} class that manages an ECS registry with sprite entities. 

\doxylink{classECSScene}{ECSScene} provides a high-\/level interface for creating and rendering sprite entities using the ECS pattern. It holds the registry, shader, and graphics buffers needed for rendering.
