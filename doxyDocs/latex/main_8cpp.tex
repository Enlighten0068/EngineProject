int main (\begin{DoxyParamCaption}{}{}\end{DoxyParamCaption})}



Entry point for the Engine\+Project application. 

Creates the main \doxylink{classApplication}{Application} instance, initializes all engine subsystems, and selects the initial scene based on the DEMO\+\_\+2\+D\+\_\+\+FIXED preprocessor macro.

If DEMO\+\_\+2\+D\+\_\+\+FIXED is defined, the application starts directly in the \doxylink{classDemo2DFixedScene}{Demo2\+DFixed\+Scene} (a 2D platformer demo with a fixed camera). Otherwise, it starts in the \doxylink{classMenuScene}{Menu\+Scene}, allowing the user to navigate to different game modes.

\begin{DoxyReturn}{Returns}
int Returns 0 on successful execution, 1 if initialization fails.
