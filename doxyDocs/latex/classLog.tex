\doxysubsection{Detailed Description}
Centralized logging system with file output and throttling. 

The \doxylink{classLog}{Log} class provides static methods for logging messages to both the console and a timestamped log file. It supports different logging levels, log throttling to prevent spam, timestamped log files. Thread-\/safe file writing via mutex to be implemented later.

\begin{DoxyNote}{Note}
All methods are static; no instantiation is required. 

The log file is created with a timestamp in the name: log\+\_\+\+YYYY-\/\+MM-\/\+DD\+\_\+\+HH-\/\+MM-\/\+SS.\+log 
\end{DoxyNote}
