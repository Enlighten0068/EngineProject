\doxysubsection{Detailed Description}
Associates a texture with an entity for 2D rendering. 

Entities with this component will be rendered as a sprite using the assigned texture. The \doxylink{classRenderSystem}{Render\+System} reads this component along with \doxylink{structComponents_1_1Transform}{Transform} to draw the entity.

\begin{DoxyNote}{Note}
The texture is stored as a shared\+\_\+ptr, allowing multiple entities to share the same texture (efficient for tilemaps or repeated sprites). 
\end{DoxyNote}
