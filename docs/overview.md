# Projeto

Motor de jogo 2D desenvolvido em C++, utilizando as bibliotecas SDL3 e openGL

## Objetivos

* Aprender o desenvolvimento de motores 
* Desenvolver jogos 2D e isométricos
* Desenvolvimento focado para sistemas Linux
* Suporte multi-plataforma: Windows e macOS 

### Objetivos a longo prazo

* Suportar networking
* Implementação 3D

## Tecnologias usadas

* C++ (standard 23)
* CMake 
* SDL3
* openGL
* git 

### Ferramentas 

* Neovim 
* Lazygit
